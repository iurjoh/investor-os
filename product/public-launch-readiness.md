# Investor OS V1 Public Launch Readiness

## Purpose

Define the evidence required before moving Investor OS V1 from controlled private beta to public sale.

## Product gates

- [x] Workbook structure implemented.
- [x] Core calculations validated with the V1 test suite.
- [x] Sample portfolio included.
- [x] User guide completed.
- [x] Product disclaimer completed.
- [ ] External beta completed with 5–10 testers.
- [ ] Beta feedback reviewed.
- [ ] Calculation regressions re-tested after beta fixes.
- [ ] Core workflow has no unresolved blockers.
- [ ] Major usability issues fixed or explicitly accepted.

## Customer experience gates

- [ ] Tester can start from the onboarding instructions without live assistance.
- [ ] Setup can be completed in a reasonable first session.
- [ ] Sample data can be removed without damaging formulas.
- [ ] User can enter buys, sells, deposits, withdrawals, fees and dividends.
- [ ] Dashboard outputs are understandable without explaining individual formulas.
- [ ] Error states clearly identify missing or invalid inputs.
- [ ] Backup/export procedure is documented.

## Commercial gates

- [ ] Final product name and positioning approved.
- [ ] Final price approved.
- [ ] Sales-page copy approved.
- [ ] Payment flow tested end-to-end.
- [ ] Delivery flow tested end-to-end.
- [ ] Refund/support process defined.
- [ ] Public distribution channel approved.

## Operational gates

- [ ] Version number and changelog established.
- [ ] Release candidate archived.
- [ ] Final workbook hash/version recorded.
- [ ] Feedback channel monitored.
- [ ] Support response process defined.
- [ ] Post-launch bug triage process defined.

## Release decision

Public release requires all product gates and customer-experience gates to be complete. Commercial and operational gates must also be complete before accepting paid orders.

Do not treat the completion of a checklist as evidence that the product is financially suitable for any particular investor. Investor OS remains a portfolio organization and education product, not a broker, automated trading system, tax-filing system, or personalized securities recommendation service.

## Post-launch V1.1 candidates

Prioritize only after V1 beta evidence is reviewed. Candidate features include:

- CAGR/XIRR
- Time-weighted return
- Correlation and volatility
- Beta
- Monte Carlo scenarios
- Rebalancing helper
- Automated prices
- Dividend calendar
- Multiple portfolios
- Advanced risk dashboard
